# ADR-0015: 코드 라이선스를 MIT로 바꾼다

- 상태: 채택
- 결정일: 2026-11-24
- 대체: ADR-0014의 「코드는 Apache-2.0을 유지한다」. README 원본·노트북 위치 결정은 그대로다.

## 맥락
- 처음 Apache-2.0을 고른 데 특별한 이유는 없었다(작성자 확인).
- 작성자의 다른 공개 저장소는 MIT로 통일돼 있다. 라이선스가 하나만 다르면 읽는 사람이 이유를 찾게 된다.
- 커밋은 모두 작성자 본인 것이라 라이선스를 바꿀 수 있다.

## 결정
- 2026-11-24부터 코드는 MIT License다. `LICENSE`를 MIT 전문으로 바꾸고, 세 언어 README의 라이선스 줄을 고친다.
- 그 전 커밋은 Apache-2.0으로 공개됐다는 사실을 README에 적는다. 이미 받아 간 사람의 권리는 소급해 바꿀 수 없다.
- 팀 몫(URFIT 이름·기획·발표 자료)과 가사에 대한 고지는 그대로다.

## 결과
- 공개 저장소의 라이선스가 MIT 하나로 맞는다.
- Apache-2.0의 특허 조항과 NOTICE 요구가 없어진다. 이 저장소에는 NOTICE 파일이 없었고 특허를 다투는 내용도 없다.
